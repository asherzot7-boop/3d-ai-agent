# Immunolab — сайт, приложение и сервер

Цифровой продукт медицинского центра Immunolab (Наманган): лаборатория, клиника, вакцинация.

| Часть | Адрес | Для кого |
|---|---|---|
| **Сайт** | `/` | Клиенты: услуги, прайс вакцинации с поиском, подготовка к анализам, путь по центру, контакты, консультант **Малохат**. 3 языка: узбекский, русский, английский. |
| **Рабочее приложение** | `/app/` | Сотрудники и руководитель: ИИ-офис из 9 агентов, 3D-модель 1 этажа, дашборд, Мактаб (обучение), Muammolar (проблемы), сканер документов. Устанавливается на телефон как приложение (PWA). |
| **Сервер** | `/api/` | Общая база, вход по PIN-коду, ИИ через ключ центра, Малохат для сайта и Telegram. |
| **Версия для Claude** | `claude/immunolab-claude.html` | Тот же файл, что раньше публиковался в claude.ai как артефакт. |

## Три способа запуска

### 1. Только сайт и демо (бесплатно, GitHub Pages)
Settings → Pages → Source: **GitHub Actions**. Каждый push в `main` публикует `public/`.
- Сайт работает полностью. Малохат отвечает по прайсу без ИИ: цены, часы работы, подготовка к анализам.
- Приложение открывается в **демо-режиме**: данные хранятся только в браузере, ИИ выключен.

### 2. Полная версия на своём сервере (рекомендуется)
Нужен любой VPS или хостинг с Node.js 18+ или Docker (Render, Railway, Fly.io, VPS в Узбекистане).

```bash
cp .env.example .env          # заполнить OWNER_PIN, STAFF_PIN, SESSION_SECRET, ANTHROPIC_API_KEY
docker compose up -d          # или: npm ci && npm start
```
Сайт будет на `http://сервер:8080/`, приложение на `/app/`. Для домена и HTTPS поставьте перед сервером Caddy, nginx или Cloudflare и задайте `TRUST_PROXY=1`.

PIN-коды сотрудников:
```bash
npm run pin                                 # список сотрудников и у кого есть PIN
npm run pin -- "Каримова Гулчирой" 4821     # задать личный PIN
npm run pin -- "Каримова Гулчирой" --remove
```
Если личного PIN нет, действует общий `STAFF_PIN`. Руководитель входит с `OWNER_PIN`.

### 3. Внутри Claude (как раньше)
Опубликуйте `claude/immunolab-claude.html` как артефакт. База, вход и ИИ идут через Claude.

## Что привязать (чек-лист)

- [ ] **Контакты сайта** в `config/site.json`: адрес, телефон, Telegram, Instagram, ссылка на карту. Затем `npm run build`. Пустые поля на сайте показаны как «уточняется».
- [ ] **Домен**: направить на сервер (способ 2) или на GitHub Pages (способ 1).
- [ ] **Ключ Claude API**: `ANTHROPIC_API_KEY` с console.anthropic.com. Включает агентов, сканер, тренажёр и Малохат с ИИ. Расход идёт с ключа центра, а не с аккаунтов сотрудников.
- [ ] **PIN-коды**: `OWNER_PIN`, `STAFF_PIN` или личные через `npm run pin`.
- [ ] **Telegram-бот Малохат**: создать бота у @BotFather и вписать `TELEGRAM_BOT_TOKEN`. Бот запускается вместе с сервером, отдельный адрес не нужен.
- [ ] **Прайс анализов**: руководитель вносит его в приложении (каталог `catalog/tests`). Малохат на сайте и в Telegram сразу начинает его использовать.

## Как это устроено

```
src/hub.html, src/modules/*.html   исходники приложения (разделы)
src/web/site.html                  сайт
src/web/runtime.js                 замена window.claude вне Claude: сервер или демо-режим
src/web/{manifest,sw.js,icon.svg}  установка на телефон, работа без сети
server/                            сервер: index.js (API, права), ai.js (Claude), store.js (база), telegram.js, pin.js
data/                              пособия и доступы (guides.json), 80 документов, прайс вакцин
config/site.json                   контакты и часы работы сайта
scripts/build.js                   сборка → public/ и claude/
public/                            готовые файлы для хостинга (собраны, лежат в git)
tests/                             API-тесты и браузерные тесты (Playwright)
```

- Разделы приложения по-прежнему работают через `window.claude.use('db' | 'user' | 'sample' | 'downloads')`. Вне Claude этот интерфейс даёт `runtime.js`: он находит сервер (`/api/health`), показывает вход по PIN и ходит в базу и ИИ через сервер. Если сервера нет, включается демо-режим.
- После входа сотрудник привязан к своему имени: выбрать другого человека без его PIN нельзя.
- Права в базе такие же, как в версии для Claude:

| Путь | Чтение | Запись |
|---|---|---|
| `catalog/*`, `docs/*`, `office/*` | все | руководитель |
| `problems/{id}`, `training/{id}`, `scans/{id}/…` | руководитель и сам сотрудник | руководитель и сам сотрудник |
| всё остальное | руководитель | руководитель |

- База хранится в одном файле `storage/db.json`. Для резервной копии достаточно копировать папку `storage/` (в Docker это том `immunolab-data`).
- ИИ: модель `claude-opus-5-5` по умолчанию, меняется через `AI_MODEL`. Включён серверный fallback на случай отказа модели. Лимиты: `AI_PER_HOUR` на сотрудника, `MALOHAT_PER_HOUR` на посетителя сайта.

## Разработка

```bash
npm ci
npm run build     # src/ + data/ + config/ → public/ и claude/
npm run dev       # сборка и сервер на :8080
npm test          # сборка, API-тесты, браузерные тесты
```
Правьте `src/`, `data/`, `config/`, затем запускайте `npm run build` и коммитьте вместе с `public/` и `claude/` (CI проверяет, что сборка актуальна).

`tools/legacy/` — прежняя сборка на Python. Её правки уже перенесены в исходники; пособия теперь редактируются прямо в `data/guides.json`.
